# Каталог расширений

Обычная сборка создаёт `artifacts/catalog.json` с настоящими хешами двух вложенных пакетов и без вымышленных ссылок на релизы.

Для публикации используйте `tools/Prepare-Release.ps1` и процедуру из `docs/RELEASING.md`. Workflow сначала публикует assets, затем переносит **тот же** сгенерированный каталог в `catalog/catalog.json` на main. HUB обновляет каталог только по запросу пользователя. Пакеты из неопубликованного каталога не объявляются скачиваемыми.

Формат манифеста и ограничения пакетов: `docs/PACKAGES.md`. SDK тем и управляющего канала: `docs/SDK.md`.
