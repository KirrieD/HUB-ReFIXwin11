# Проверка 1.1.1

25 октября 2026 года, Windows, .NET Framework 4.8, C# 5.

`build.ps1 -BuildTests` успешно собирает HUB, общий SDK, загрузчик, помощник обновления и оба модуля. Итоговый `artifacts/ReFix.Tests.exe`: **133 passed; 0 failed**. Проверки Windows hotkey, named pipe и WPF выполнены в обычном пользовательском окружении вне ограниченной песочницы; данные изолированы в тестовых каталогах. Настоящие настройки и установка пользователя не изменяются.

Регрессии воспроизводили потерю уведомлений после атомарной замены `controls.json`: непосредственное чтение в FileSystemWatcher могло увидеть недоступный файл и оставить старую клавишу. Исправление объединяет события и ограниченно повторяет чтение; постоянного фонового опроса нет. Проверены назначение, очистка и сброс как через отдельный экземпляр хранилища, так и в отдельном работающем процессе QuickNote. Проверяется настоящая доставка сообщений окна регистрации клавиш.

Подсветка проверяется по заполнению назначенных клавиш и более яркому выделению выбранного сочетания, включая PageDown и внутренние псевдонимы WPF Prior/Next. Проверяются сохранение настройки автоскрытия, флажок в HUB и отказ скрытия при выключенной настройке.

Обновление состояния установленного или работающего модуля не публикует промежуточный OFF/пустую версию и не посылает лишних уведомлений. Проверены удаление работающего QuickNote со штатным выходом, сохранение заметок/темы/соседнего модуля, отказ удаления через junction, сохранение активного фикса при неудачной отмене и удаление после подтверждённой отмены.

Десять проверок сети используют настоящий локальный HTTP-сервер: 403/429 API и официальный резервный адрес, временный 503, ограничение повторов, Retry-After, отсутствие релиза, некорректные SHA, размер и посторонние перенаправления. Отдельно прочитана реальная цепочка официального адреса GitHub latest/download/update.json → versioned asset → GitHub CDN. Источник конкретного 403 у пользователя без исходных заголовков не установлен; резервный путь и обработка временных ошибок покрыты тестами.

SmartScreen: у локального Core проверен статус Authenticode `NotSigned`. Пользователь уточнил текст «Система защитила ваш компьютер», а не имя обнаруженной угрозы. Репутационное предупреждение не объявляется исправленным: нужна доверенная подпись издателя и репутация / распространение через Store. Защита, исключения и хранилище сертификатов не менялись.

После обновления самого HUB необходимо обновить уже установленные пакеты утилит до 1.1.1, чтобы они получили исправленный SDK: выключить → обновить → включить. Существующие пакеты автоматически не заменяются.
