# Пользовательские источники

В **Настройки → Ссылки** указаны папка HUB и официальный репозиторий. Основной репозиторий фиксирован: `https://github.com/KirrieD/HUB-ReFIXwin11`. Пользовательские источники не меняют источник обновления самого HUB.

Можно добавить несколько локальных папок и произвольное количество публичных Git-репозиториев. Фиксированного ограничения на число репозиториев нет; файл настроек ограничен 1 МиБ. Изменения сохраняются в `%LOCALAPPDATA%\ReFIXHub\sources.json`. Каталог обновляется после закрытия окна ссылок или вручную кнопкой обновления каталога.

Репозиторий должен содержать совместимый каталог `catalog/catalog.json` схемы 1 с массивом `Modules`, как в официальном каталоге проекта. Каждый модуль имеет уникальный `Id`, `Name`, `Version`, `MinHubVersion`, `Kind`, `Description`, HTTPS `PackageUrl` и `Sha256`. ZIP содержит `module.json` и файлы модуля по правилам SDK. Произвольный репозиторий исходного кода без каталога и готового пакета не является расширением HUB.

Для GitHub и GitLab автоматически проверяются ветки `main` и `master`; для остальных серверов используется путь Gitea `/raw/branch/<ветка>/catalog/catalog.json`. Для другого размещения укажите явную HTTPS-ссылку на каталог. Приватные репозитории с авторизацией не поддерживаются.

ZIP должен находиться в пределах указанного репозитория на том же HTTPS-сервере. Для GitHub разрешены штатные перенаправления на серверы загрузки release assets. Перед установкой проверяются SHA-256, структура архива и манифест. Чтение каталога не запускает код расширений.

Локальная папка может содержать `catalog.json` с пакетами или самостоятельные ZIP с `module.json`. Для самостоятельных ZIP сканируются первые 200 файлов. Папка и репозиторий сохраняются как происхождение модуля: другой источник не может заменить установленный модуль с тем же идентификатором. Идентификаторы официальных утилит `quiet-mixer`, `quick-note`, `task-menu` зарезервированы.

После удаления источника установленную утилиту можно запускать, останавливать и удалять. Для установки обновлений источник необходимо добавить снова. Снятая из каталога версия перестаёт предлагаться как обновление.
