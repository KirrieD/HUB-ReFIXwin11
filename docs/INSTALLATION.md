# Установка HUB ReFIX

Версия Windows: Windows 11, Microsoft .NET Framework 4.8. Права администратора не требуются.

Скачайте `HUB-ReFIX-Setup-1.1.0.exe` из релиза и нажмите «Установить». Setup проверит встроенный полный ZIP, попросит работающий установленный HUB завершиться и установит приложение в `%LOCALAPPDATA%\ReFIXHub\app`. Будут созданы ярлык в меню «Пуск» и запуск при входе в Windows. Пользовательские настройки, заметки и модули хранятся отдельно; неизвестные файлы установленной папки сохраняются. При успешной проверке установленная версия показывает «Все установлено».

Для portable распакуйте **весь** `HUB-ReFIXwin11-1.1.0.zip` и запустите `HUB-ReFIX.exe`. Bootstrap проверяет комплектность и контрольные суммы перед запуском `HUB-ReFIX.Core.exe`. Portable сам не меняет реестр. При повреждении или неполной распаковке появляется «Требуется настройка для корректной работы» со списком причин; повторно распакуйте полный архив. Не запускайте Core напрямую.

Уже установленная версия 1.0 требует одного ручного обновления через Setup: в ней ещё нет обновляющего клиента. Setup поддерживает корректное завершение старой монолитной версии и новой Core. Если приложение не завершилось, закройте HUB через меню в трее и повторите установку. Принудительного завершения процессов нет.

Перед заменой файлов Setup сохраняет прежние затрагиваемые файлы в `%LOCALAPPDATA%\ReFIXHub\install-backups\<дата-идентификатор>`. Если файл совпал по имени с новым комплектом, но отсутствует в прежнем списке принадлежности (включая первую установку поверх 1.0), его исходные байты сохраняются в резервной папке, путь показывается после установки. Остальные неизвестные файлы остаются на месте. При ошибке копирования Setup восстанавливает заменённые файлы и удаляет только созданные им новые файлы; резервная папка сохраняется для восстановления.

Запись о прежнем QuietMixer переносится только для известного пути `%LOCALAPPDATA%\QuietMixer\QuietMixer.exe` и точного известного значения автозапуска. Маркер `migration-quiet-mixer.json` имеет те же поля, что и установка через `tools\Install.ps1`; существующий маркер сохраняется.

Для изолированной проверки точного встроенного архива без установки, реестра, ярлыков и запуска HUB используйте:

```powershell
HUB-ReFIX-Setup-1.1.0.exe --extract-to C:\Temp\hub-payload-test
```

Папка назначения должна быть пустой. Код завершения `0` означает успешную распаковку и проверку всего комплекта. Сборка Setup выполняется `tools\Build-Setup.ps1` после формирования portable ZIP. Setup и Bootstrap компилируются из одних исходников и не зависят от `ReFix.Shared.dll` во время собственной работы.
