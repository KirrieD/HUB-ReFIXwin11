# HUB ReFIX Implementation Plan

> **For agentic workers:** use superpowers:subagent-driven-development for isolated components and a final independent review.

**Goal:** Runnable Windows hub, shared theme SDK, real module management, GitHub catalogue and installable package.

**Architecture:** Separate module processes share theme.json and a user-scoped control protocol; host presents/installs packages and checks real state. Theme editor stays modeless.

**Tech Stack:** C# 5, .NET Framework 4.8, WPF, Win32, System.Web.Extensions JSON, SHA-256, ZIP; local Roslyn build.

**Spec:** ../specs/2026-10-25-hub-design.md

## Global Constraints
- Windows 11, no additional web runtime or NuGet restore.
- No polling/network refresh while hidden; no fake ON state.
- Restrict downloads to the named repository and archive paths to staging root.
- Do not modify the existing standalone QuietMixer.
- User's GitHub repository is empty; no push/publication authorized yet.

## Review Focus
- ZIP traversal, corrupt archives, missing executables and interrupted updates.
- Stale PID/state files and status commands that fail or hang.
- Editing styles must keep HUB interactive; unrelated foreground windows hide HUB.
- System/high contrast and unreadable custom color/opacity combinations.
- Startup paths with spaces, duplicate instances and clean application exit.
