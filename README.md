# HUB ReFIX для Windows 11

Небольшая панель с утилитами улучшающие пользовательскую часть для работы с ОС Windows 11.
* Загрузка новых утилит происходит через HUB с этого GIT репозитория.
* Все утилиты имеющие интерфейс адаптированы под единый стиль WIN 11 или Пользовательские настройки.

!!! ТРЕБУЕТСЯ: Windows 11 и .NET Framework 4.8; 

!!! НЕ ТРЕБУЕТСЯ: Права администратора и сторонний софт.

Что имеется на данный момент:
1. **Микшер громкости** - Адаптация QuietMixer. Вызывается нажатием на "Динамик". Убирается ESC или кликом на любую часть экрана.
2. **Быстрая заметка** - Простейшие заметки на рабочем экране. Вызывается через панель HUB.

Что планируется:
**Мониторинг ресурсов** - Адаптированный мониторинг ресурсов ЦП, ОЗУ, Видео память, трафик дисков, трафик сети и система выявления задач, которые потребляют много ресурсов. 
1. Будет добавлена возможность вызова диспетчера задач и мониторинга ресурсов. 
2. Динамическая система потребления (ПО, которые будут в реальном времени потреблять ресурсы выше определенных значений, будут выводиться в отдельное окно мониторинга Warning и Fatal).
* Программы по типу ИГР, Браузера и аналогичных можно будет отключить, так как они изначально потребляют много ресурса ПК.

**Мониторинг для Zapret** - Адаптированный мониторинг пропускной способности для пулов пакетов Zapret.
Из-за специфики работы Zapret и использования ресурсов через консоль для отпинговки, будет переработан мониторинг для упрощения получения данных.
1. Мониторинг будет производиться в выделенной памяти, чтобы не нагружать основную систему и обновление будет происходить 1 раз в час.
2. Учет VPN, если будет запущен VPN сервис - выйдет оповещение о возможном конфлике работы сервисов с возможностями:
* Отключить мониторинг, Отключить VPN, Оставить и мониториг и VPN.
3. Автоматическое включение более быстрого варианта zapret из списка.
* Это нужно для того, чтобы включение было не в ручную - это можно будет отключить, чтобы каждый раз не переключаться на новый вариант, если уже включенный работает стабильно.
* Обновление Zapret из оригинального GIT репозитория автора.
- При выходе новой версии, выйдет оповещение для обновления.

**Пользовательские утилиты** - Возможность автономного расширения списка в HUB для подгрузки собственных решений пользователей путем создания собственного репозитория и добавление его в "Пользовательский список".
Списки будут делиться на 3 вида:
* Основной - Разработанный внутри HUB-ReFix
* Добавочный - Отдельный список вносимый в оригинальный репозиторий разрешенный создателем.
* Пользовательский - собственный список добавленных репозиториев сторонних авторов самим пользователем.

Так же будет создан мини форум для пользователей и разработчиков, где каждый сможет делиться своими ссылками на собственные утилиты.

Внешние репозитории можно будет добавить по ссылке внутри HUB и после обновления каталога, новые решения должны добавиться в список "Пользовательские" и быть доступны для установки, включения и выключения.
* Добавление пользовательских решений в глобальный HUB с припиской "Сторонняя утилита", устанавливая такие решения вы подтверждаете, что создатели HUD не несут рисков с установкой сторонних расширений.

**Защитник** - Добавление мониторинга вредоносного кода, изолирование подобных решений, если они были установлены и добавление ссылки вредоносного репозитория в черный список у всех клиентов приложения.
* Каждая утилита обязана использовать только общедоступные ресурсы без использования прав администратора/ Root прав и иных систем, кроме разрешенных.
* При вставке ссылки в список "пользовательский" на репозиторий, который был добавлен в черный список, выйдет уведомление "Репозиторий и автор были добавлены в черный список, будьте аккуратны с использованием этих утилит". После подтверждения, список утилит добавиться в список "пользовательские", но с пометкой "Черный список". 

**Фикс Windows 11** - Отключение излишних мониторингов, телеметрий и иных подсистем, которые не влияют на работу ОС и иных систем связанных с безопасностью и оптимизацией.
* Данный фикс будет разрабатываться постепенно и тестироваться так, чтобы при установке клиентом не было краша самой ОС или иных проблем, которые могут быть из-за отключения.

## Запуск и установка
(ВРЕМЕННОЕ РЕШЕНИЕ)
Распакуйте portable ZIP целиком и откройте `HUB-ReFIX.exe`. Не запускайте EXE прямо внутри ZIP. Для установки текущему пользователю откройте `tools/Install.cmd`: файлы попадут в `%LOCALAPPDATA%\ReFIXHub\app`, появится ярлык «HUB ReFIX» в меню «Пуск», автозапуск HKCU `ReFIXHub` и откроется панель. Команда автозапуска содержит путь в кавычках и `--background`. В PowerShell можно передать `-NoShortcut` и/или `-NoLaunch` в Install.ps1.

Данные хранятся рядом с app, отдельно: `modules/`, `state/`, `theme.json`, `assets/`, заметка `notes/quick-note.txt`. Для тестов предусмотрен `REFIX_DATA_ROOT`; установщик и удаление требуют убрать эту переменную, чтобы не затронуть тестовую среду.

**Ctrl+Alt+H** показывает/скрывает HUB; щелчок по значку в трее открывает панель. Крестик скрывает окно, «Выйти» в трее завершает HUB. Переход в другое приложение скрывает панель. Оформление открывается отдельным немодальным окном: HUB остаётся доступен, переход в его настройки не закрывает панель. Автозапуск переключается в интерфейсе. Модули работают отдельными процессами, выход из HUB оставляет их работающими.

## Модули и состояния

- **NO** — нет проверенного установленного пакета. Кнопка установки распакует вложенный локальный пакет.
- **OFF** — пакет установлен, утилита не активна.
- **ON** — процесс отвечает по управляющему каналу. Для будущих постоянных исправлений потребуется успешная проверка их команды состояния.

Установка не запускает модуль автоматически. Ошибки проверки отображаются отдельно: нажатие кнопки само по себе не означает ON. Обновление каталога и загрузки выполняются только по явному действию. Вложенные пакеты работают без публикации GitHub-релиза и без сети. На момент разработки удалённый репозиторий [KirrieD/HUB-ReFIXwin11](https://github.com/KirrieD/HUB-ReFIXwin11) пуст, релизы ещё не опубликованы; ошибка удалённого обновления не должна мешать локальному каталогу. Будущие пакеты загружаются по HTTPS, проверяются SHA-256 и устанавливаются через staging с проверкой путей и откатом. SHA-256 — проверка целостности относительно каталога, **не подпись издателя**; бинарники не подписаны.

Системная тема учитывает оформление Windows. Ручная тема позволяет настроить цвета RGB/hex, прозрачность, свечение, фон из локального изображения, его положение/масштаб/размытие, скругления и размер шрифта. Изображение копируется в пользовательские assets. Изменения видны сразу и сохраняются с небольшой задержкой.

В скрытом состоянии нет опроса статусов/UI и сетевого опроса: используются события процессов, файлов и окон, IPC. Проверка статусов с таймером работает только при видимом HUB. При фоновом автозапуске сначала загружается лёгкий трей; WPF-интерфейс создаётся при первом вызове. После открытия интерфейс остаётся в памяти ради быстрого повторного вызова. Расход RAM ненулевой; результаты локального измерения описаны в `docs/VERIFICATION.md` исходного репозитория.

## Удаление

По желанию сначала выключите модули кнопкой OFF. Запустите `tools/Uninstall.cmd` из установленной папки или portable архива. Скрипт запросит штатный выход HUB, удалит только известные файлы приложения/вложенные ZIP, соответствующий автозапуск и свой ярлык. Другие процессы принудительно не завершаются. Заметки, тема, assets, установленные модули и состояние **сохраняются** в `%LOCALAPPDATA%\ReFIXHub`; неизвестные файлы тоже остаются. Автоматического удаления данных/модулей на данный момент нет. Повторная установка использует сохранённые данные.

## Сборка

```powershell
.\build.ps1 -Test -Package
```

Нужен компилятор C# (скрипт выбирает Roslyn Visual Studio 2022 Community, затем системный .NET Framework). NuGet-зависимостей нет. Результат: `artifacts/HUB-ReFIXwin11/HUB-ReFIX.exe` и `artifacts/HUB-ReFIXwin11-1.0.0.zip`. Для подготовки GitHub-выпуска см. [docs/RELEASING.md](docs/RELEASING.md). Сборка и упаковка ничего не устанавливают и не публикуют.
