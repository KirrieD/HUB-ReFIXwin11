# HUB ReFIX для Windows 11

Новое простенькое приложение для Windows 11. Сделанное **KirrieD** совместно с **GPT**. ~~Немного навайбкодил в своем углу~~
Что из себя представляет мой HUB-REFIXwin11: Небольшая панель с утилитами улучшающие пользовательскую часть для работы с ОС Windows 11.
* Добавляет новые утилиты, фиксит некоторые баги у винды и в целом позволяет улучшить как визуал, так и работу системы.
* Все утилиты имеющие интерфейс адаптированы под единый стиль WIN 11 или Пользовательские настройки.
* Загрузка новых утилит происходит через HUB с этого GIT репозитория.
* HUB умеет чекать этот репозиторий для того, чтобы Я и возможно ВЫ могли скачать то, что я сделал в свободное время.

### !!! ТРЕБУЕТСЯ: <ins>Windows 11 и .NET Framework 4.8</ins>. 
### !!! НЕ ТРЕБУЕТСЯ: <ins>Права администратора и сторонний софт</ins>.

Возможно требования изменятся, но я не планирую этого делать. ПО не требует ничего, кроме того, чтобы было установлено и по сути запущено.
Дальше просто установи и включи все, что хочешь и то, что имеется.

## Что имеется на данный момент:
1. **Микшер громкости** - Адаптация QuietMixer. Вызывается нажатием на "Динамик". Убирается ESC или кликом на любую часть экрана.
2. **Быстрая заметка** - Простейшие заметки на рабочем экране. Вызывается через панель HUB.
3. **Синхронизация с GIT** - Можно в любой момент проверить наличие обновлений ПО и обновить каталог.

# Что планируется:
**Мониторинг ресурсов** - Адаптированный мониторинг ресурсов ЦП, ОЗУ, Видео память, трафик дисков, трафик сети и систему выявления задач, которые потребляют много ресурсов. 
1. Будет добавлены различные виджеты с ресурсами ПК.
2. Будет добавлена возможность вызова диспетчера задач и мониторинга ресурсов.
3. Динамическая система потребления (ПО, которые будут в реальном времени потреблять ресурсы выше определенных значений, будут выводиться в отдельное окно мониторинга Warning и Fatal).
   - Программы по типу ИГР, Браузера и аналогичных можно будет отключить, так как они изначально потребляют много ресурса ПК.
   - Так же можно будет отключить распознавания и иных программ, по желанию из списка процессов.

**Мониторинг для Zapret** - Адаптированный мониторинг пропускной способности для пулов пакетов Zapret.
Из-за специфики работы Zapret и использования ресурсов через консоль для отпинговки, будет переработан мониторинг для упрощения получения данных.
1. Мониторинг будет производиться в выделенной памяти, чтобы не нагружать основную систему и обновление будет происходить 1 раз в час.
2. Учет VPN, если будет запущен VPN сервис - выйдет оповещение о возможном конфлике работы сервисов с возможностями:
   - Отключить мониторинг, Отключить VPN, Оставить и мониториг и VPN.
3. Автоматическое включение более быстрого варианта zapret из списка.
   - Это нужно для того, чтобы включение было не в ручную - это можно будет отключить, чтобы каждый раз не переключаться на новый вариант, если уже включенный работает стабильно.
   - Обновление Zapret из оригинального GIT репозитория автора.
     - При выходе новой версии, выйдет оповещение для обновления.

**Пользовательские утилиты** - Возможность автономного расширения списка в HUB для подгрузки собственных решений пользователей путем создания собственного репозитория и добавление его в "Пользовательский список".
Списки будут делиться на 3 вида:
* **Основной** - Ссылка на оригинальный репозиторий HUB-ReFix самим KirrieD.
* **Добавочный** - Отдельный список репозиториев в специальный список разрешенный создателем.
* **Пользовательский** - Личный список добавленных репозиториев сторонних авторов самим пользователем.

Так же будет создан мини форум для пользователей и разработчиков, где каждый сможет делиться своими ссылками на собственные утилиты.

Внешние репозитории можно будет добавить по ссылке внутри HUB и после обновления каталога, новые решения должны добавиться в список "Пользовательские" и быть доступны для установки, включения и выключения.
* Добавление пользовательских решений в глобальный HUB с припиской "Сторонняя утилита", устанавливая такие решения вы подтверждаете, что создатели HUD не несут рисков с установкой сторонних расширений.

**Защитник** - Добавление мониторинга вредоносного кода, изолирование подобных решений, если они были установлены и добавление ссылки вредоносного репозитория в черный список у всех клиентов приложения.
* Каждая утилита обязана использовать только общедоступные ресурсы без использования прав администратора/ Root прав и иных систем, кроме разрешенных.
* При вставке ссылки в список "пользовательский" на репозиторий, который был добавлен в черный список, выйдет уведомление: "Репозиторий и автор были добавлены в черный список, будьте аккуратны с использованием этих утилит".
  - После подтверждения, список утилит добавиться в список "пользовательские", но с пометкой "WARNING". 

**Фикс Windows 11** - Отключение излишних мониторингов, телеметрий и иных подсистем, которые не влияют на работу ОС и иных систем связанных с безопасностью и оптимизацией.
* Данный фикс будет разрабатываться постепенно и тестироваться так, чтобы при установке клиентом не было краша самой ОС или иных проблем, которые могут быть из-за отключения.

`Сейчас список не полный, он будет меняться и разрабатываться с учетом новых фишек и интересных решений, как от разработчика HUB, так и иных пользователей, которые дадут добро на использование их утилит.`

# Запуск и установка
Доступны два варианта:

# ТОНКАЯ:
1. Установка через SETUP - скачиваете и производите стандартную установку.
2. Через ZIP архив - скачиваете, разархивируете куда хотите и пользуетесь, ПО само все остальное подтянет. 

# ТОЛСТАЯ: (Мало актуальная)
1. **ZIP:** распакуйте архив целиком и запустите `HUB-ReFIX.exe`. Программа проверяет комплектность, контрольные суммы и .NET Framework. При отсутствующих или повреждённых компонентах выводится «Требуется настройка для корректной работы» с перечнем причин. ZIP не меняет автозапуск сам по себе.
2. **Setup:** запустите `HUB-ReFIX-Setup-1.1.1.exe`. Установщик проверит вложенный ZIP, установит HUB текущему пользователю в `%LOCALAPPDATA%\ReFIXHub\app`, создаст ярлык и автозапуск. После успешной проверки установленный HUB показывает «Все установлено». Неизвестные файлы и данные сохраняются; совпавшие файлы сохраняются в резервной копии. Старый HUB закрывается штатно.

Скачивание: [последний выпуск](https://github.com/KirrieD/HUB-ReFIXwin11/releases/latest). Не запускайте EXE прямо внутри ZIP. Совместимые вспомогательные `tools/Install.cmd` и `tools/Uninstall.cmd` остаются в архиве.

Темы, клавиши, установленные модули и заметки хранятся отдельно от файлов приложения в `%LOCALAPPDATA%\ReFIXHub`. Удаление приложения сохраняет эти данные.

# Обновления HUB-ReFIX

При обнаружении новой версии HUB предлагает «Обновить» или «Отменить». 
  - Отмена сохраняет текущую версию.
  - После согласия пакет скачивается, проверяются SHA-256 и состав файлов, затем приложение закрывается, обновляется и автоматически запускается снова.
  - При ошибке замены выполняется откат.
`Обновление не удаляет заметки, темы и настройки клавиш.`

## Проверка обновлений:

Проверка выполняется при запуске и по кнопке «Проверить обновления»; 
  - Скрытого непрерывного сетевого опроса нет.
  - После отказа ту же версию можно установить ручной проверкой.

При ограничении GitHub API (403/429) используется официальный публичный файл последнего релиза. Временные сетевые ошибки повторяются ограниченное число раз с учётом указаний сервера; адреса, размер и контрольные суммы по-прежнему проверяются.

**Начиная с 1.1.** поддерживается автоматическое обновление.

## Управление и назначение клавиш

Раздел **Управление** в боковой панели и трее открывает отдельное немодальное окно **Назначение клавиш**. 
* Здесь можно изменить сочетание, отключить действие или восстановить назначения по умолчанию.
* Клавиатура показывает физические клавиши с латинскими/русскими подписями; назначения не зависят от текущей раскладки.
* Во время записи Escape отменяет изменение, Backspace/Delete без модификаторов очищает сочетание.

По умолчанию Ctrl+Alt+H показывает/скрывает HUB, Ctrl+Alt+V — Показать/Скрыть микшер. Глобальная клавиша заметки изначально отключена. Escape скрывает соответствующее открытое окно; Ctrl+S сохраняет заметку. 
* Эти локальные назначения тоже можно изменить. Стрелки и Tab остаются стандартным управлением ползунками и фокусом.
* Глобальное сочетание должно содержать Ctrl или Alt; конфликтующие и зарезервированные Windows сочетания отклоняются.
* Статус рядом с действием показывает фактическую регистрацию: выключенный модуль не занимает свою клавишу, а ошибка регистрации не выдаётся за активное сочетание.
* Изменения применяются к уже работающим модулям.

Чтобы исправление передачи клавиш из 1.1.1 действовало в ранее установленных утилитах, обновите и их: выключите модуль, нажмите «Обновить», затем включите снова. Обновление самого HUB не заменяет уже установленные пакеты модулей автоматически.

Флажок **Скрывать автоматически** в боковой панели HUB сохраняется между запусками. Если включён, переход в другое приложение скрывает HUB; если выключен, HUB остаётся открытым. Крестик и назначенная клавиша скрытия работают в обоих режимах.

Флажок запуска микшера вместе с HUB запускает только установленный проверенный модуль; фоновой загрузки нет. 
- Включение/выключение микшера в HUB меняет желаемый запуск; его можно отдельно переопределить в настройках.
- У адаптированного микшера нет собственного переключателя автозапуска.

Установщик распознаёт только известный standalone `%LOCALAPPDATA%\QuietMixer\QuietMixer.exe` с соответствующим значением `QuietMixer` в автозапуске и оставляет маркер миграции.   
Новый HUB начиная с 1.1. штатно останавливает старый процесс, устанавливает/обновляет проверенный модуль и проверяет его работу; только затем убирает старое совпадающее значение автозапуска. 
  - При ошибке оно сохраняется. Старые EXE и данные не удаляются.

## Модули и состояния

- **NO** — нет проверенного установленного пакета. Кнопка установки распакует вложенный локальный пакет.
  -  Для установленных модулей 1.0 доступно обновление до 1.1.1; предыдущая версия сохраняется до успешного завершения установки.
- **OFF** — пакет установлен, утилита не активна.
- **ON** — процесс отвечает по управляющему каналу.
  - Для будущих постоянных исправлений потребуется успешная проверка их команды состояния.

Установка не запускает модуль автоматически. Ошибки проверки отображаются отдельно: нажатие кнопки само по себе не означает ON. 

Обновление каталога и загрузки выполняются только по явному действию. Вложенные пакеты работают без публикации GitHub-релиза и без сети. 
  - Исходники и выпуски доступны в [KirrieD/HUB-ReFIXwin11](https://github.com/KirrieD/HUB-ReFIXwin11); ошибка удалённого обновления не мешает локальному каталогу.
  - Будущие пакеты загружаются по HTTPS, проверяются SHA-256 и устанавливаются через staging с проверкой путей и откатом.
  - SHA-256 — проверка целостности относительно каталога, **не подпись издателя**; бинарники не подписаны.

Системная тема учитывает оформление Windows. Ручная тема позволяет настроить цвета RGB/hex, прозрачность, свечение, фон из локального изображения, его положение/масштаб/размытие, скругления и размер шрифта. Изображение копируется в пользовательские assets. Изменения видны сразу и сохраняются с небольшой задержкой.

В скрытом состоянии нет опроса статусов/UI и сетевого опроса: используются события процессов, файлов и окон, IPC. 

Проверка статусов с таймером работает только при видимом HUB. При фоновом автозапуске сначала загружается лёгкий трей; WPF-интерфейс создаётся при первом вызове. 

После открытия интерфейс остаётся в памяти ради быстрого повторного вызова. Расход RAM ненулевой; результаты локального измерения описаны в `docs/VERIFICATION.md` исходного репозитория.

# Удаление

Кнопка **Удалить утилиту** в карточке установленного модуля запрашивает подтверждение, штатно останавливает процесс и удаляет его пакеты. Для фикса сначала требуется подтверждённая отмена изменений; при её ошибке файлы сохраняются. Заметки, общая тема и настройки клавиш сохраняются. Для микшера также отключается его запуск вместе с HUB.

- По желанию сначала выключите модули кнопкой OFF.
- Запустите `tools/Uninstall.cmd` из установленной папки или portable архива.
  - Скрипт запросит штатный выход HUB, удалит только известные файлы приложения/вложенные ZIP, соответствующий автозапуск и свой ярлык.
    - Другие процессы принудительно не завершаются.
    - Заметки, тема, assets, установленные модули и состояние **сохраняются** в `%LOCALAPPDATA%\ReFIXHub`; неизвестные файлы тоже остаются.
      - Повторная установка использует сохранённые данные.

# Предупреждение Windows при первом запуске

Текущие EXE не имеют доверенной цифровой подписи издателя. Сообщение SmartScreen «Система Windows защитила ваш компьютер» может появляться для нового или малоизвестного файла; оно само по себе не является уведомлением об обнаруженном вирусе. Каждый новый неподписанный выпуск набирает репутацию отдельно. Подпись доверенным сертификатом снижает вероятность предупреждений, но не гарантирует их отсутствие: [документация Microsoft](https://learn.microsoft.com/windows/apps/package-and-deploy/smartscreen-reputation). Защита Windows не отключается, исключения и самоподписанные сертификаты программа не устанавливает.
